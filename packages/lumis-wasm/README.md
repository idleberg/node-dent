# @nsis/lumis-wasm

> Self-contained Lumis language package for NSIS: the Tree-sitter parser plus its matching highlight queries.

![License](https://img.shields.io/npm/l/@nsis%2Flumis-wasm?style=for-the-badge)
[![Version](https://img.shields.io/npm/v/@nsis/lumis-wasm?style=for-the-badge)](https://www.npmjs.org/package/@nsis/lumis-wasm)

You usually don't install this directly — [`@nsis/lumis`](../lumis#readme) depends on it and points Lumis at it via `packageName`.

## Versioning

The major/minor version tracks the Tree-sitter ABI that Lumis supports (`LANGUAGE_PACKAGE_VERSION_RANGE`, currently `0.26`), **not** the NSIS grammar. Lumis rejects a language package whose version falls outside that range, and resolves it from the CDN as `<packageName>@0.26/lumis.json`. The grammar version it was built from is recorded as `parser.upstreamVersion` in `lumis.json`.

> [!IMPORTANT]
> Only ever release this package with a **patch** changeset. A minor bump would move it to `0.27.x` and Lumis would refuse to load it. The major/minor only changes when Lumis raises the supported ABI range.

## Contents

`lumis.json`, `tree-sitter-nsis.wasm` and the entry point are generated by `npm run build` from the installed `tree-sitter-nsis` package.
